# Contributing

Development targets `forward` through focused pull requests. Use Node.js 24.x and pnpm 10.28.0. Keep dependencies locked, preserve source provenance, and run the repository's release checks before requesting review.

Do not add credentials, personal data, mutable runtime source downloads, write tools, arbitrary package execution, or cross-app access. Do not update pinned upstream examples without a reviewed manifest, digest, notice, and compatibility refresh.
